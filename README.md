# UI-тесты для сервиса "Яндекс Самокат"

Автоматизированные UI-тесты для веб-приложения [qa-scooter.praktikum-services.ru](https://qa-scooter.praktikum-services.ru/).  
Проект реализован с использованием **Page Object Pattern** и параметризации тестов JUnit.

---

## Используемые технологии

| Компонент          | Версия      | Назначение                                      |
|--------------------|-------------|-------------------------------------------------|
| Java               | 11          | Основной язык разработки                        |
| Maven              | 4.0.0       | Система сборки и управления зависимостями       |
| JUnit              | 4.13.2      | Фреймворк для написания и запуска тестов        |
| Selenium WebDriver | 4.35.0      | Работа с браузерами (Chrome, Firefox)           |
| ChromeDriver /     |  Актуальная | Драйверы для управления браузерами              |
